# OIBSIP Internship Projects

A collection of web development projects completed as part of the Oasis Infobyte internship program.

## Projects

- `Task2_CALCULATOR` — calculator project.
- `Task2_TRIBUTE_PAGE` — tribute page project.
- `Task3_BASIC_TO-DO_WEBAPP` — basic to-do web application.

## Getting started

Open the project folder you want to explore. For static web projects, open the relevant `index.html` file in a browser. No shared build process is defined at the repository root; check each project folder for its own files and requirements.
